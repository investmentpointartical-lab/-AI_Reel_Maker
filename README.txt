AI REEL MAKER
=============

One page: index.html. Nothing else is needed.

HOW TO USE
1. Open index.html in Chrome or Edge.
2. First time: the "Your AI keys" window opens. Paste the keys you have and press Save (you can open it again with ⚙ Keys).
3. Press + to add a picture (poster, table, chart, product photo) - or drag / paste it into the box.
4. Type what you want, e.g. "Make a reel from this picture's data", and press ➤ (or Enter).
5. The reel appears in the preview. Press ▶ Play to watch it.
6. Want changes? Just type them in the same box: "make the title shorter", "add one more slide", "write it in Gujarati".
7. Press ⬇ Download video. The MP4 (1080 x 1920) goes to Downloads, ready for Instagram / Facebook / YouTube Shorts.
   The video has no sound: add music in the app when you post. Copy the ready caption with hashtags under the preview.

Background "AI picture": every slide gets its own AI photo that matches what the slide says (made one after the other,
about 10-30 seconds each, with the Pollinations key). In "Edit the text yourself" each slide has a "Picture idea" box and a
"New AI picture" button to change just that picture. You can also say it in the chat: "use photos of Indian families".

Extra (optional): Colour of the reel, Background (No picture / AI picture / My picture), and "Edit the text yourself".

THE KEYS (all free)
- Google Gemini     aistudio.google.com  -> Get API key -> Create API key          (best: reads pictures well)
- OpenRouter        openrouter.ai        -> profile picture -> Keys -> Create Key
- Groq              console.groq.com     -> API Keys -> Create API Key (copy it at once, it is shown only once)
- Pollinations      enter.pollinations.ai -> sign in -> keys                       (only for "AI picture" backgrounds)
The page uses them by itself: Gemini first, then OpenRouter, then Groq when one is busy or over its daily limit.
No keys at all? It still works: the page gives you a message to paste into the Gemini app (gemini.google.com),
and you paste Gemini's answer back.

Keys are saved only in your browser. They are NOT inside index.html, so the file is safe to upload anywhere.
On another phone or computer, open ⚙ Keys once and paste them again.

PUT IT ON INFINITYFREE (free hosting)
1. Open https://www.infinityfree.com and sign up (your own email and password).
2. Create a hosting account and choose a free address (for example yourname.infinityfreeapp.com).
3. In the control panel open "File Manager" and go into the folder "htdocs".
4. Delete the sample files there, then upload index.html from this folder.
5. Open your address, press ⚙ Keys and paste your keys (once on each device).

Music: choose a song under Reel details > Music, or 'Upload music from this device'. The song plays with the reel and goes into the downloaded video (fades out at the end). To add a song for everyone: put the file in the music folder and add a line to SONGS in index.html.
